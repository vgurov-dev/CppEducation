# Реализация и тестирование связных списков на C++

Решение алгоритмической задачи **21. Merge Two Sorted Lists** с платформы LeetCode в локальной среде разработки. Проект содержит необходимую инфраструктуру для инициализации, отладки и визуализации структуры данных "Односвязный список" (Singly Linked List).

## 📌 Описание структуры данных

В основе проекта лежит структура узла `ListNode`, полностью совместимая со спецификацией LeetCode:

* **`val` (int)**: Целочисленное значение, хранящееся в текущем узле.
* **`next` (ListNode*)**: Указатель на следующий узел в цепочке. Равен `nullptr`, если элемент является последним.

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode* next) : val(x), next(next) {}
};
```

## 🛠️ Вспомогательный инструментарий

Для удобства локального тестирования в проект интегрированы две утилиты:

1. **`createList(const std::vector<int>& nums)`**  
   Автоматически выделяет память в куче (`Heap`) через оператор `new` и выстраивает последовательную цепочку узлов на основе переданного динамического массива.
2. **`printList(ListNode* head)`**  
   Последовательно итерирует список от головы (`head`) до терминального узла (`nullptr`) и визуализирует связи в консоли в формате:  
   `1 -> 2 -> 4 -> nullptr`

## 🧠 Ключевые концепции для реализации алгоритма слияния

При написании тела функции `mergeTwoLists` используются следующие паттерны:
* **Two Pointers (Два указателя)**: Параллельный проход по двум спискам с помощью независимых курсоров.
* **Dummy Node Technique**: Использование фиктивного головного узла на стеке для исключения проверок на инициализацию результирующего списка.
* **Pointer Manipulation**: Эффективная перепривязка адресов `next` без лишнего выделения памяти в куче.
